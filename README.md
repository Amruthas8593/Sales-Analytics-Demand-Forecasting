# Sales Analytics & Demand Forecasting for Dairy Products

End-to-end portfolio project combining Python, SQL, machine learning and Power BI for sales performance, demand and pricing analysis.

## Business objective
Analyse transaction-level dairy sales data to understand revenue and demand patterns, compare products and regions, evaluate discount behaviour, and test machine-learning approaches for demand forecasting.

## Dataset
50,000 transaction records covering 2023–2025 with date, product, category, region, channel, customer type, unit price, units sold and discount fields.

## Workflow
Data quality → feature engineering → EDA → pricing/inventory analysis → four regression models → Power BI reporting.

## Machine learning
The notebook compares Linear Regression, Decision Tree, Support Vector Regression and Neural Network models using MAE, RMSE and R². Results are calculated at runtime rather than hard-coded into the README.

## Repository structure
- data/ — source and Power BI-ready datasets
- notebooks/ — reproducible analysis and modelling
- sql/ — business queries
- dashboard/ — Power BI build notes
- images/ — portfolio visuals
- requirements.txt — dependencies

## Run
Install requirements.txt and open notebooks/sales_demand_forecasting.ipynb in Jupyter.

## Skills demonstrated
Python, Pandas, NumPy, Scikit-learn, SQL, Power BI, EDA, regression modelling, model evaluation and business reporting.
